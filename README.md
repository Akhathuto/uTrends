# uTrend - AI Content Suite

**Your personal AI assistant and autonomous agent for content creation.**

uTrend is an all-in-one, AI-powered platform designed to streamline the entire workflow for modern content creators. From discovering the next viral trend to generating full video scripts, creating media assets, and planning strategic growth, uTrend provides a comprehensive suite of tools powered by Google's Gemini API.

---

### Key Features

-   **🤖 Autonomous AI Agent (Nolo AI):** Go beyond simple chat. Give the agent high-level commands (e.g., "Create a video about space travel and suggest thumbnails"), and it will autonomously use the app's tools to complete the multi-step task, showing you its work in a real-time task log.
-   **🎨 Comprehensive Creation Suite:** Generate high-quality images, videos, logos, and animations. Write complete, structured video scripts, and design click-worthy thumbnail concepts from a single prompt.
-   **📈 Real-time Insights & Strategy:** Discover what's trending right now on YouTube and TikTok with live, interactive trend cards. Get custom growth plans, monetization guides, and in-depth keyword analysis.
-   **🎙️ Live & Interactive Avatars:** Design your own AI avatar and engage in real-time voice conversations. Bring your characters to life by generating lip-synced video animations with custom dialogue and gestures.
-   **📚 Persistent Content Library:** Save your best scripts, growth plans, and thumbnail ideas to your personal "My Content" library, which persists in your browser's local storage for easy access.

---

### Technology Stack

-   **Frontend:** React, TypeScript, Tailwind CSS
-   **AI Engine:** Google Gemini API (including Gemini 2.5 Pro, Imagen 4.0, Veo, and the Live API for real-time voice)
-   **Core AI Features:** Leverages advanced Function Calling for autonomous agent capabilities and Google Search grounding for real-time information.

### How It Works

The application is a single-page app that runs entirely in your browser.

-   **Navigation:** Use the sidebar on the left to navigate between the different tools, which are organized into logical groups like Content Creation and Strategy & Growth.
-   **Dashboard:** The dashboard serves as your command center, offering quick access to all tools and displaying real-time trends.
-   **Data Persistence:** The "My Content" feature uses your browser's `localStorage` to save your work. Clearing your browser data will also clear your saved content.
